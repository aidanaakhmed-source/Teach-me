# Teach Me

## 1. Мақсаты

Teach Me — Django негізіндегі шағын оқу құралы: пайдаланушы конспект мәтінін
енгізеді, жүйе одан 3–8 карточка (сұрақ / жауап / дәйексөз) құрастырады.
Әр карточкадағы `source_quote` конспект мәтінінен алынған дәйексөз болуы
міндетті, ал әр карточка дерекқорда `Source` пен байланысқан `Flashcard`
ретінде сақталады.

Жобаның екі режимі бар:

- `demo` — интернетке шықпайтын, тұрақты демо-мәтіннен әрдайым 3 карточка
  құратын режим. Бұл режим барлық ортада бірдей нәтиже береді.
- `live` — сыртқы Gemini API арқылы карточка жасайтын қосымша режим.
  Тек `GEMINI_API_KEY` мен `GEMINI_MODEL` орнатылған жағдайда ғана жұмыс
  істейді.
